# Project Glossary

Applies when `GLOSSARY.md` or `GLOSSARY-INDEX.md` exists at the project root, or the task names domain vocabulary.

- Read the glossary before naming domain concepts; use its terms, never an `Avoid` synonym.
- Each entry is one or two sentences plus an `Avoid:` line; domain terms only.
- Create it lazily on the first real term; add the index when a second context appears.

Full rule, examples, and rationale: [`standards/project-glossary.md`](../standards/project-glossary.md). Read it before creating or editing a glossary.
