# Everyday Engineering

A daily checklist for non-trivial code changes; skip it for one-line fixes and explicit explorations.

- Build an end-to-end thin slice before going deep; spike when that answers the open question cheaper.
- Build a fast, deterministic reproduction loop before hypothesizing about a bug.
- Every fixed bug gets a regression test.
- Status reports lead with the symptom; a blocked message carries a path forward.

Full checklist and rationale: [`standards/everyday-engineering.md`](../standards/everyday-engineering.md). Read it before starting a feature or a debugging session.
