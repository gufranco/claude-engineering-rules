# committed, then add your own entries.

# glob per line. Blank lines and lines starting with `#` are ignored.

# repository only; every other dangerous-command rule still applies.
#
# Add a repository here only when you own it alone. For anything with
# reviewers, use a feature branch and a PR.
#
# A missing `solo-repos.txt` means an empty allowlist, so every protected
# branch stays protected.
